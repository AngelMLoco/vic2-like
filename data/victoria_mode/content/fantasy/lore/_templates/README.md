# Plantillas de la biblia de lore — Chronicles of Aether

Estas plantillas están VACÍAS a propósito: el lore definitivo lo aporta el autor.
Para usarlas, copia una plantilla a `content/fantasy/lore/<nombre>.json` (fuera de `_templates/`,
que no se carga), rellena las entradas y añade `fantasy` a `content_packs` del escenario.

El cargador (`VLoreLoader`) valida los campos obligatorios de cada tipo. Esquema completo:
`docs/LoreBibleSchema.md`.
